---
name: Homepage map contract
description: Required map behavior on the public main page.
---

The public main page must visibly load the real Den Haag map with listing pins. Pins need mouse-over/focus preview cards, and neighborhood areas must support selecting multiple neighborhoods before opening discovery.

**Why:** Replacing the map with a privacy explainer, rendering an empty map, or reducing selection to one neighborhood removes the product's primary discovery model.

**How to apply:** Treat map-first rendering, populated icons with previews, and multi-neighborhood selection as homepage acceptance criteria for redesigns, privacy changes, and release validation.
